# Extended script (about 1,750 words)

1. Load the `open-loops` skill first and plan the loops before you write.
2. **Format:** plain paragraphs and nothing else. No headings, timestamps or [VISUAL] notes. Aim for 1,700–1,800 words, which is about 10–11 minutes at roughly 2.8 words per second.
3. **Structure:**
   - a cold open or pattern-break hook
   - the promise loop within the first 45 seconds
   - context
   - escalation, with a twist at about 35–50%
   - the climax
   - the payoff, with the promise loop closed last
   - a reflection
   - a question for the comments
4. **Subscribe call-outs:** three in total, at about 20%, about 65% and the end. Wrap each one in a bridge loop that points ahead.
5. **Voice (the user's hard requirement: never robotic):**
   - Write like a person talking to one viewer.
   - Use contractions, "you" and "I", and honest reactions ("this line genuinely stopped me").
   - Add light humour and mix short fragments with flowing sentences.
   - Tell moments rather than lists.
   - Banned stiff transitions: "Think about that." "Here's something to hold on to." "Read that again."
6. **Accuracy:** only real, documented facts. Mark approximate dates and debated points ("around", "most historians think", "one theory"). Paraphrased quotes must keep the exact meaning.
7. **After the script, deliver:**
   - the word count
   - the LOOP MAP (from open-loops)
   - the checklist
   - accuracy notes with sources
   - the **Shorts hook script** (`shorts-hook` skill), so the user can record both at once
8. Save the script to a .txt file for the voiceover and alignment.
